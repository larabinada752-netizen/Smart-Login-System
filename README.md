# Smart Login System 💻🔐

## Description
I personally developed this **Smart Login System** using the **C programming language**.  
It is a complete console-based project that allows users to **register new accounts, login, and change passwords**.  
I worked hard to design, code, and test every part myself, including **data saving, verification, and editing features**.  
This project helped me strengthen my understanding of **file handling, structures, and system logic in C**.  
I’m proud of how it turned out and how it runs smoothly in the terminal! ✨

---
## How to Run
1. Clone or download the repository  
2. Open the folder in **PowerShell** or **VS Code terminal**  
3. Compile the code

## Run the program:

./login


 Follow the on-screen menu to:

 1/Register a new user

 2/Login

 3/Change password

 4/Exit the program


## Features
- Register a new user with a username and password  
- Login with existing user credentials  
- Change password for an existing user  
- Save and load users from a text file (`users.txt`)  
- Simple and intuitive console interface  
- Easy to run and test
